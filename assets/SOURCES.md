# Visual assets and design references

| Asset | Original source | Use |
| --- | --- | --- |
| `kozminski.svg` | [Official Kozminski visual identity book, flat logo, page 5](https://www.kozminski.edu.pl/sites/leon/files/files/logobook_mini_2018.pdf) | Original flat artwork extracted as vector paths; its colors, proportions and Polish wordmark are preserved. |
| `scrapling.png` | [Scrapling repository logo](https://raw.githubusercontent.com/D4Vinci/Scrapling/main/docs/assets/logo.png) | Original unmodified framework logo. |
| `icons/*.svg` | [Lucide icon sources](https://github.com/lucide-icons/lucide/tree/main/icons) | Database, network, circle-check and file-text vectors. |
| `icons/LICENSE` | [Lucide license](https://github.com/lucide-icons/lucide/blob/main/LICENSE) | Original attribution/license notices. |

The university and framework marks identify the institution requested by the author and the software used. They retain their respective trademark and artwork rights; the repository's Apache license does not relicense these marks. The report is an academic project report, not a journal publication or an institutional endorsement.

Typography and layout references: [JMLR, Kronecker Graphs (2010)](https://www.jmlr.org/papers/volume11/leskovec10a/leskovec10a.pdf) and [WWW, Statistical Properties of Community Structure (2008)](https://cs.stanford.edu/~jure/pubs/ncp-www08.pdf). These papers inspired the design only. No findings or body text from them were copied into the report.

Report body, tables, charts and links are monochrome. The only colored artwork is the original university and Scrapling logos. Customize `report_config.json` and run `python generate_report.py` to reuse the layout.
